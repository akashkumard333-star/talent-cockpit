## 🔹 Project Overview

Talent Cockpit is a full-stack SAP Cloud Application Programming Model (CAP) application built to manage:

- Employees  
- Skills  
- Project Assignments  
- Project Demands  
- Utilization KPIs  

The system follows SAP Fiori design principles and is deployed to SAP BTP Cloud Foundry using HTML5 Repository.

---

## 🏗️ Architecture

SAPUI5 Frontend
↓
AppRouter (HTML5 Runtime)
↓
CAP OData V4 Service
↓
SAP HANA / SQLite


---

## 🎯 Key Capabilities

### 👥 Employee Management
- Advanced filtering with F4 Help
- List Report page
- Object Page with tab navigation
- Editable sections

### 📊 Skills Module
- Add / Edit / Delete Skills
- Rating validation (1–5)
- Last Used tracking

### 📁 Assignments
- Allocation % control
- Date range validation
- OData association expansion

### 📌 Project Demands
- Skill requirement per project
- Minimum rating enforcement
- Dynamic filtering

### 📈 KPI Dashboard
- Total Employees
- Active Employees
- Total Projects
- Utilization %
